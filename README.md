# 👗 Fashion Picker

A stylish and interactive outfit selection app that lets users mix, match and explore clothing combinations with ease. Built with **HTML**, **CSS** and **JavaScript**, it’s perfect for fashion lovers and trend explorers.

---

## 🚀 Features

- 🌟 **Outfit generator** : Instantly create unique looks by combining tops and bottoms.  
- ⚡ **Responsive design** : Works seamlessly across mobile, tablet and desktop.  
- 🎨 **Interactive previews** : Hover and click effects to visualize clothing in style.  
- 🔄 **Smart suggestions** : Recommends fashion matches based on colors and trends.  
- 🛠️ **Easy customization** : Swap images, styles and animations directly in code.  
- 💡 **Engaging experience** : Makes picking outfits fun, creative and effortless.  
- ✨ **Modern UI** : Clean and minimalist design that highlights fashion pieces.
